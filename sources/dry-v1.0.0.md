# Claude용 건조시럽 계산기 원라인 시작점

당신은 지금 이 공개 저장소를 읽고, 사용자가 바로 내려받아 쓸 수 있는 **단일 HTML 건조시럽 환산계수·칭량 질량 계산기**를 완성해야 한다. 추가 질문은 하지 말고 아래 순서대로 진행하라.

1. 같은 릴리스의 [BUILD-SPEC.md](https://raw.githubusercontent.com/guinnessNet/dry-syrup-calculator/v1.0.0/BUILD-SPEC.md), [정본 데이터](https://raw.githubusercontent.com/guinnessNet/dry-syrup-calculator/v1.0.0/data/dry-syrups-v1.json), [계산 사례](https://raw.githubusercontent.com/guinnessNet/dry-syrup-calculator/v1.0.0/tests/calculation-cases-v1.json)를 모두 읽는다.
2. 데이터의 `schemaVersion`이 `1`이고 `dataVersion`이 `1.0.0`인지 확인한다.
3. 아래 fallback JSON의 정규화 SHA-256이 `DATA_SHA256` 값과 일치하는지 확인한다. 링크의 JSON을 읽을 수 있으면 그 파일을 우선하고, 읽지 못하면 fallback을 사용한다.
4. `BUILD-SPEC.md`의 `MUST`와 `MUST NOT`을 모두 지킨다. UI의 색상·글꼴·레이아웃은 자유롭게 설계한다.
5. 실행 중 네트워크 요청이 전혀 필요 없도록 10개 제품 데이터를 HTML 내부에 내장한다.
6. 구현 후 계산 사례의 정상값을 자체 확인하고, 잘못된 입력이 화면에 오류를 내는지 확인한다.
7. 완성한 `.html` 파일을 다운로드할 수 있게 제공한다. 구현 설명은 짧게 덧붙인다.

## 링크를 일부 읽지 못해도 지켜야 할 핵심 계약

- 화면 입력은 **기본 10제품 검색/선택과 처방용량(mL)**뿐이다.
- 출력은 **환산계수(g/mL)와 칭량 질량(g)**뿐이다.
- 체중·연령·적정용량·최대용량·환자 식별정보·목록 밖 제품 수동 입력은 만들지 않는다.
- 외부 라이브러리나 실행 중 네트워크 요청 없이 한 HTML 파일로 작동해야 한다.
- 사용자 입력은 `innerHTML`에 넣지 말고 안전한 DOM 속성이나 `textContent`로 표시한다.
- 계산식은 `K = C / (1000 × P)`, `M = 처방용량 × K`이며 중간값을 반올림하지 않는다.
