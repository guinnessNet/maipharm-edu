# 교육자료 샘플관 설계

## 목적

`edu.maipharm.com/dry/`의 제작 지침과 완성 결과물을 분리한다. 사용자가 Claude에 `/dry/` 경로를 제시했을 때 샘플 정답을 읽는 대신 지침과 재료만 읽도록 유지하고, 사람이 교육 결과를 비교할 때는 `/sample/`을 이용한다.

## 공개 경로

- `/dry/`: 기존 건조시럽 계산기 제작 지침. 내용과 동작을 변경하지 않는다.
- `/sample/`: 모든 교육자료 샘플을 모으는 목록 페이지.
- `/sample/dry/first/`: 최소 입력만으로 처음 생성된 건조시럽 계산기.
- `/sample/dry/final/`: 지침과 검증을 거쳐 개선된 건조시럽 계산기.

## 원본 파일

- 첫 결과: `/Users/maicto/Downloads/건조시럽_환산계수_계산기.html`
- 개선 결과: `/Users/maicto/Downloads/dry-syrup-calculator (3).html`

원본 HTML의 계산 로직과 화면은 수정하지 않고 각 공개 경로의 `index.html`로 복제한다.

## 목록 화면

`/sample/`에는 건조시럽 계산기 항목과 두 개의 실행 링크를 둔다. 두 결과는 각각 `첫 결과`와 `개선·검증 결과`로 표시하고, 정답 배포가 아니라 제작 전후를 비교하는 교육용 자료임을 밝힌다.

## 분리 원칙

- `/dry/`에서 `/sample/`로 가는 링크를 추가하지 않는다.
- 샘플 페이지에서 `/dry/`의 지침이나 데이터 파일을 실행 중 불러오지 않는다.
- 두 계산기는 각 폴더에서 독립 실행한다.
- 향후 샘플은 `/sample/<주제>/<단계>/` 규칙으로 추가한다.

## 검증 기준

- 네 공개 URL이 HTTPS로 응답한다.
- `/dry/` 파일의 배포 전후 해시가 같다.
- 첫 결과와 개선 결과의 배포 파일 해시가 각 원본 파일과 같다.
- `/sample/`의 두 링크가 올바른 결과 페이지를 연다.
- 계산기 두 페이지가 외부 프레임 없이 독립적으로 표시된다.
